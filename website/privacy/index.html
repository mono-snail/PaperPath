01 / 文档与本机处理

核心文档处理留在你的设备上。

PDF 处理、扫描复核、文字识别及隐私检测在设备端完成。PaperPath 不会将 PDF 内容、提取正文或手写签名发送到 PaperPath 处理服务器。

导入会在应用存储中创建工作副本，不修改导入前的原件。本地数据可能包括 PDF、识别文字、缩略图、书签、历史版本、你选择保存的签名及输出回执。

PaperPath 的私有文档库不包含在设备自动备份中。删除应用或更换设备前，请先导出需要保留的文件。

02 / 可选 iCloud 元数据

同步范围有限，并且默认关闭。

开启后，PaperPath 可通过你的 iCloud 账户同步阅读位置、书签、标签、工作流状态、文件指纹及回执元数据。

同步不包括 PDF 数据、文件名、OCR 文字、提取内容、密码和签名。iCloud 存储由 Apple 按其条款处理。

关闭同步只会停止后续同步。请使用应用内的“删除已同步元数据”移除已经存储在 iCloud 中的 PaperPath 元数据。

03 / 权限与通知

每项系统权限都对应一个明确功能。

  • 相机权限用于扫描文档与身份二维码。
  • 应用锁使用系统认证及可用的面容 ID；PaperPath 不获取你的生物识别模板。
  • 可选的到期提醒通知不包含 PDF 名称或正文。

你可以在系统设置中随时更改这些权限。

04 / 购买

付款信息由 Apple 处理。

首发计划为一次付费下载，无 PaperPath 订阅或应用内功能解锁。Apple 处理 App Store 付款、下载历史与退款；PaperPath 不获取银行卡信息。各地区价格以上架后的 App Store 为准。

05 / 分享、诊断与外部服务

文件只会通过你主动发起的操作离开。

当你导出或分享文件后，目标应用或服务会按其政策处理该副本。交付包可能包含文档与回执元数据，请在分享前核对。

可选的私密诊断文件可能包含应用与设备信息、文档数量、存储统计及相关设置；不包含 PDF 数据、文件名、提取正文、密码或签名。生成诊断不会自动发送文件。

PaperPath 未集成广告 SDK 或第三方分析 SDK。Apple 可能根据你的设备与 App Store 设置另行提供商店或崩溃信息。

06 / 保留与删除

本地数据与同步数据分别控制。

工作副本及废纸篓可在 PaperPath 内管理。“删除全部本地数据”会移除本地 PaperPath 文档及关联数据，但不会删除你导入前的原件。

已同步的元数据需要使用单独的删除控制项。已导出的文件、其他应用持有的副本及外部备份，需要在对应位置分别管理。

07 / 重要边界

自动检查不能替代人工复核。

请在分享前复核。

自动隐私检测可能遗漏信息。输出副本中的永久脱敏无法撤销。文件与页面检查不认证内容准确性、身份或法律合规性。

08 / 联系与更新

隐私问题与数据请求。

请发送邮件至 hello@monoware.app 联系 MonoWare，或使用 MonoWare 支持表单。请勿通过邮件发送私密 PDF 或账户凭据。

如果后续版本改变上述数据处理方式，本页面会在对应版本发布前更新。页面顶部的生效日期用于标识当前修订版。
