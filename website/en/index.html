A few things worth knowing.

Does PaperPath upload my PDFs?

Core PDF processing, OCR and privacy detection run on your device. System sharing and optional iCloud metadata sync use the services you choose. Metadata sync does not sync PDF files.

What does Verified Output check?

It creates an image-based flattened copy, reopens its pages and records file checks. It does not certify content accuracy, signer identity or legal compliance. Flattening removes searchable text, links, forms and editable layers.

Is this a subscription?

No. The planned launch model is a US$9.99 one-time paid download, with no separate PaperPath Pro unlock. The App Store will show the local price when available.

Can I use it on Mac?

The current release is designed for iPhone and iPad. Mac compatibility is still unverified, so Mac support is not included in the launch promise.

Are my PDFs backed up automatically?

The private document library is excluded from automatic device backups. Optional iCloud metadata sync does not back up PDFs. Export important documents before deleting the app or changing devices.

Can I work with PDFs without an internet connection?

Merge, split, compress and OCR run on your device. Downloading PaperPath, Apple purchases and optional iCloud metadata sync use the internet. Sharing or exporting may send files to the destination you choose.

Can I merge PDFs and change their order locally?

Merge supported unlocked PDFs and drag the selected sources into order before creating the combined copy. Original files stay unchanged. Resource limits still apply to large jobs.

Does PDF compression reduce quality?

Choose Readable, Balanced or Compact and review a sampled size estimate. Compression rebuilds pages as images and removes searchable text, links, forms and editable notes. If the rebuilt copy would be larger, PaperPath keeps the smaller original.
