01 / PRIVACY

자동으로 찾고. 직접 확인하고.
영구적으로 제거합니다.

PaperPath는 지원되는 민감한 정보를 기기에서 스캔한 뒤 후보, 페이지와 출처를 명확히 보여 줍니다. 제거할 항목과 검은색 가림 또는 흰색 제거 방식은 사용자가 결정합니다.

자동 개인정보 스캔

민감한 정보를 한 줄씩 찾을 필요가 없습니다.

지원되는 이메일 주소, 전화번호, 날짜, 텍스트 영역을 분류해 보여 줍니다. 실행 전 해당 PDF 페이지로 돌아가 확인할 수 있습니다.

  • 스캔과 인식은 기기에서 처리
  • 후보를 유형과 페이지별로 정리
  • 선택 안 함, 전체, 개별 선택 지원

04 / HOW IT WORKS

원본 보존이 기본입니다.

01

원본 가져오기

PaperPath는 로컬 작업 사본을 만들며 가져온 원본 파일은 변경하지 않습니다.

02

완성과 검토

서명, 정리, 인식 또는 가림을 진행합니다. 중요한 작업은 먼저 확인하고 긴 작업은 다시 시작할 수 있습니다.

03

검증 후 공유

출력 페이지를 다시 열고 파일 검사를 기록한 뒤 실제로 검토한 사본을 전달합니다.

05 / FAQ

중요한 질문에
명확하게 답합니다.

민감한 정보가 자동으로 제거되나요?

PaperPath는 지원되는 유형의 민감한 정보를 기기에서 자동으로 스캔하지만 검토 없이 삭제하지 않습니다. 각 항목을 선택하고 원본 PDF 페이지를 확인하며 가림 방식을 고른 뒤 최종 작업을 확정합니다.

가림 처리한 내용을 복구할 수 있나요?

복구할 수 없습니다. 영구 가림 사본에서는 해당 내용을 되돌릴 수 없으므로 실행 전에 명확한 확인 화면을 표시합니다. 가져온 원본 파일은 다시 처리할 수 있도록 보존됩니다.

PDF가 서버에 업로드되나요?

핵심 PDF 처리, OCR과 개인정보 탐지는 기기에서 실행됩니다. 시스템 공유 대상을 직접 선택하거나 선택적 iCloud 메타데이터 동기화를 켠 경우에만 해당 시스템 서비스 범위로 데이터가 전달됩니다.

가림 처리 외에 무엇을 할 수 있나요?

읽기, 양식 입력, 손글씨 서명, 주석, 스캔, OCR, 병합, 분할, 페이지 정리, 압축, 암호 보호, Office·이미지·텍스트 내보내기와 Verified Output 전달을 지원합니다.

구독이 필요한가요?

PaperPath 정기 구독은 없습니다. 무료 다운로드에 Verified Output 1회가 포함되며, 일회성 구매로 Verified Output과 일괄 전달을 무제한 사용할 수 있습니다.
