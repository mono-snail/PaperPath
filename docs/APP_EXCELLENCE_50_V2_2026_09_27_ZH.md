## 压力结果

前七行耗时来自 xcresult 的**整个用例**，包含准备/校验，不能冒充为生产操作精确耗时或真机基准；RSS 只报告实际验证的增量上限。OCR 另有操作内部计时及采样峰值。

| 场景 | 用例总耗时 | 通过的内存/响应约束 |
| --- | ---: | --- |
| 256 MiB 稀疏 PDF 导入 | 0.338 秒 | 峰值 RSS 增量 <192 MiB，独立副本有效 |
| 128 MiB 稀疏 PDF 交付审计 | 0.094 秒 | 峰值 RSS 增量 <256 MiB |
| 200 页合并 | 0.030 秒 | 峰值 RSS 增量 <256 MiB |
| 200 页版本比较 | 0.311 秒 | 峰值 RSS 增量 <192 MiB |
| 40 页压缩 | 0.745 秒 | 峰值 RSS 增量 <256 MiB |
| 40 页安全分享 | 0.712 秒 | 峰值 RSS 增量 <256 MiB |
| 长文档取消 | 0.091 秒 | 用例内取消返回 <250 毫秒 |
| 1000 页 OCR 断点恢复 | 8.774 秒 | 操作 8.685958958 秒，峰值 RSS 增量 <512 MiB |

OCR 恢复 992 页预设检查点，实际 Vision 识别剩余 8 页；并非从头识别 1000 页。实测 RSS 基线 645 MiB、采样峰值 920 MiB，按原始字节差取整为 +274 MiB（各显示值分别取整）。其余压力没有导出精确峰值，不虚构具体占用。稀疏大文件主要验证流式 I/O 和字节预算，不代表同体积高分辨率扫描件。
