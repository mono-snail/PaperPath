PaperPath is a paid-upfront iPhone and iPad PDF app. The download purchase includes its features; no subscription, in-app feature purchase, PaperPath account, or login is required.

On first launch, choose “Try a Sample PDF” to open fictional local samples, or “Go to Home” to import a PDF through Files. If documents already exist, onboarding offers “Open My PDF”. Camera capture requires a physical device. Samples and Files import can be reviewed without camera permission.

Suggested review path:
1. Open a sample PDF or import a PDF through Files.
2. Read and annotate it, fill supported interactive form fields, or place a handwritten signature.
3. Open privacy review, inspect detected candidates in context, and explicitly confirm any permanent redaction.
4. Create Verified Output, review warnings and the receipt, and preview the resulting PDF before sharing. Repeat output and test batch delivery; no further purchase is needed.

PDF processing, OCR, and sensitive-information detection run on device. Automatic detection may miss information. A handwritten signature is a visual mark, not an identity certificate.

Verified Output creates a separate image-based PDF and local check receipt. It reopens the output pages and records file checks. Searchable text, links, interactive form fields, and editable layers are removed from that copy. Warnings remain visible. The checks do not certify document accuracy, a signer's identity, or legal compliance.

The source file selected for import is preserved. The private document library is excluded from automatic device backups, so important files should be exported before uninstalling or changing devices.

Optional iCloud metadata sync is disabled by default. It can synchronize reading position, bookmarks, tags, workflow state, file fingerprints, and receipt metadata; it does not back up PDF files or extracted body text. Settings → Privacy & Data explains these boundaries offline.

There is no review login. App Review contact details are entered separately in App Store Connect and must be verified by the publisher.
