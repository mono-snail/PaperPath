# PaperPath V41：任务通道与自适应工作台

## 产品方向

本轮不增加孤立功能，集中解决“能力很多，但入口同时展开、上下文重复、输出选择过长”的流程问题。资料库改为“工作 / 创建 / 交付”三条持久化任务通道；文档工具改为“建议 / 收藏 / 全部”；导出改为“推荐 / PDF / Office / 图像”。文档工作台只在存在风险、恢复点或过期凭证时展示决策证据，单页文档不再常驻无效翻页控件。

核心定位保持为：在本机完成重要 PDF，保护导入原件，并在分享前生成可验证产物。

  - https://helpx-origin-ew1.aws116.adobeitc.com/ro/acrobat/mobile/get-started/faqs.html
  - https://helpx.adobe.com/acrobat/mobile/organize-pdfs/extract-pages.html

  - https://pdfexpert.com/
  - https://pdfexpert.com/ios/features/pdf-edit-ios
- UPDF 以功能覆盖广、文件管理、多标签和工具栏显示控制为重点。PaperPath 不继续堆叠同屏功能，而是通过任务通道压缩可见范围，并在低内存告警时主动释放 PDF 预览缓存。
  - https://updf.com/tech-spec/
  - https://updf.com/whats-new/

## 本轮交付

- 资料库“工作 / 创建 / 交付”任务通道。
- 通道状态、工具视图和导出类别跨启动记忆。
- 搜索不受通道裁剪影响。
- 资料库分区移除 `AnyView` 类型擦除。
- 文档工具“建议 / 收藏 / 全部”分层。
- 基于真实文档动作规划的上下文工具建议。
- 不可用工具原因折叠展示。
- 风险驱动的工作台决策栏。
- 固定高度横向证据轨。
- 单页文档自动移除无效页导航。
- 底部主操作视觉降噪和触感反馈。
- 导出“推荐 / PDF / Office / 图像”分类。
- 文档适配的推荐输出集合。
- 可关闭、按长度自适应时长的全局通知。
- 系统内存告警时主动清理两级 PDF 预览缓存。
- OOXML 临时文件明确排除系统备份。
- 新增界面文案的简体中文覆盖。

## 相比竞品新增优势

- 相比 Acrobat 的统一 More tools 路径，PaperPath 在资料库阶段就按工作意图裁剪功能，同时保留全局搜索。
- 相比 PDF Expert 的工具自定义，PaperPath 同时结合文档状态生成上下文建议，并保留人工收藏。
- 相比 UPDF 的广功能和工具栏控制，PaperPath 把“是否需要显示证据”交给确定性文档状态，而不是长期占用阅读区域。
- 三者都强调编辑和转换；PaperPath 继续独占“原件不改、输出重开验证、凭证可追溯、Office 临时内容不进备份”的完整本地交付链。

## 当前剩余短板

- iPad 仍使用堆栈式资料库到文档导航，尚未形成真正的双栏持续工作台。
- 工具建议来自确定性规则和文档状态，尚未支持用户自定义建议排序。
- 全局通知已有关闭能力，但删除后的“撤销”仍主要依赖废纸篓入口。
- 当前缓存会在内存告警时清空，但尚未根据热状态动态降低正在生成的缩略图分辨率。
- 本轮按要求未运行单元测试、UI 测试、截图回归和发布门禁。

## 下一轮精准方向

1. 为 iPad 增加资料库与当前 PDF 的双栏工作模式，同时保留 iPhone 紧凑导航。
2. 为删除、批量标签和页面重排增加带时限的可操作通知。
3. 根据内存和温度状态动态下调预览质量，而不只在告警后清空。
4. 将交付通道扩展为来源、生产中、待复核、可分享四列状态板。
5. 单独执行深色模式、辅助字号、窄屏和 iPad 横屏视觉验收。
