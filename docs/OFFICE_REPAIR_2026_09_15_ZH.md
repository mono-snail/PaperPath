# Office 定向修复与回归

范围：修复前一轮公开样本暴露的编号层级、表格对应关系，以及未保留内容的提示。
不扩展到原始 Office 公式、图表对象或 SmartArt 的完整重建。

## 实现

### Word

- 识别字母、罗马数字、多级数字及无空格编号，避免把相邻编号条目并成一段。
- 同一基线中被 PDFKit 拆开的编号和正文重新组合。
- 按源文字位置保留父子缩进；普通段落仍使用原来的页面对齐计算。
- 保留源编号文字，包含重新从 1 开始和跳到 10 的情况，不生成可能改写编号的自动续号。
- 列表不再被误识别成两列表格。编号仍是可编辑文字，并非 Word 自动编号对象。

### Excel

- 不再把 PDFKit 的每个文字片段直接当成一行，先按基线归组。
- 复用现有、有操作数量上限的 PDF 矢量扫描器提取表格边界。
- 有可靠边界时按单元格区间定位，而非按文字左端定位，保留右对齐数值及空白单元格的位置。
- 带边框的多行单元格可合并，保留单元格内换行；表格外说明文字不按表格列拆开。
- 无可靠边界时按坐标推断并记录对应页码，明确要求核对，不宣称完整结构还原。
- 无文字页保留同名空工作表并记录页码，不再静默跳过。
- 移除每行只取前 64 项的静默截断；超出工作簿总体预算或 Excel 列限制时明确报错。
- 输出启用单元格换行和对应行高，避免多行文字在独立应用中被遮住。

### 提示与结果

- 新增可持久化的内容提示，随导出记录保存，也写入 Office 文件的自定义属性。
- Word 提醒编号/段落、页眉页脚与参考图限制；Excel 明示未包含图表、图片、条件格式、
  公式及透视关系；PPT 明示页面图片而非逐对象可编辑，文字搜索依赖目标应用。
- 无文字页、未生成参考图、推断表格位置分别列出源页码；分段转换按原始页码显示。
- 旧记录缺少新字段仍可解码，并按格式显示保守的模式提示。
- 结果首层使用“已转换，请核对内容”和“成果已保存到本机”，不把可分享误当内容完整。
- 成果列表的“需处理”筛选包含这些结果；“生产证据”入口改为“查看转换检查结果”。
- 最大辅助字号实测发现底部分享按钮遮挡检查入口，已限制操作区字号；
  提示正文仍支持动态字号，检查入口具有独立无障碍标识。

## 回归方法

沿用前轮原稿、参考 PDF 和 SHA-256，不换成更简单的输入。
共 9 份 Apache POI 公开样本、58 页 PDF，经生产 `makeTextExport` 导出。
新增诊断步骤通过 `retainOfficeExport` 保存，再创建新的模型/存储实例重开，
检查提示与原记录相同。结果文件用 LibreOffice 26.2.6.3 独立重开并导 PDF，
检查正文、数值、OOXML 单元格及并列截图。

重点断言：

- a/b/c、重新编号和 10/11/12/13 各自独立成段，子项缩进大于父项。
- 条件格式首页的 Products1、Products2、Grades、Quarters、Customers2 与右列逐行对应；
  Book tour 对应同一单元格中的两行文字。
- 透视结果页中 `a -> 1 / 空 / 1`、`c -> 空 / 3 / 3`、总计 `1 / 3 / 4`。
- 所有源页有对应工作表；十个空文字页都有提示，无数字静默丢失。
- 提示随保存重开保留，并写入实际输出文件。
- 实际 UI 搜索历史成果，打开提示和检查详情；普通及最大辅助字号分别验证。

证据及最终结果见 [回归证据](../design/office-fix-2026-09-15/README.md)。

最终结果：9/9 生产导出与独立重开完成；80/80 针对性内容、结构和持久化检查通过；
历史成果的端到端 UI 测试通过，覆盖普通及最大辅助字号，0 失败。
最终视觉复核后移除了详情页大标题，内容限制置于首屏，并再次跑过同一 UI 测试。

本轮三项定向修复已完成，可以进入版本整理和物料准备，不建议继续无边界加功能。
这不是整体提审放行：真实目标 Office 应用兼容性、真机验证和下面列出的完整测试问题，
仍应作为发布检查清单处理；对外不能宣传复杂 Office 无损还原或完整可编辑。

## 验证过程中的阻碍

- 中断后原模拟器和临时工具目录已不存在，重新创建了专用模拟器及临时环境，未动其他项目设备。
- 原完整测试目标有两处既有 `PaperPathModel.errorMessage` 引用导致无法编译。
  没有改这些无关单测；新增 `PaperPathOfficeRegression` Scheme 隔离本轮 UI 测试。
- 一轮测试构建失败后误用了旧 App 产物。报告没有新增持久化字段，随后更正并重跑；
  `pass-2` 不作为保存重开验证依据。
- UI 首轮错误使用了不存在的导航标识；第二轮发现真实的最大字号底部遮挡，
  保留失败日志及截图，没有将这些轮次标为通过。

## 剩余边界

这次修复的是可复现的内容对应错误，不代表无损版式还原。字体、间距、边框、
合并对象语义以及无边框/多表格布局仍需人工核对。图表图片和原生公式没有新增恢复能力。
PPT 的透明文字在 LibreOffice 再导 PDF 时仍可能不保留，包中文字存在不等于跨应用搜索通过。
LibreOffice 不是 Microsoft Office 或 iWork；未做这些目标应用的真实打开/编辑验收，
也未运行完整 XCTest 套件或真机压力测试。本轮没有提交、推送、修改版本或提审。
