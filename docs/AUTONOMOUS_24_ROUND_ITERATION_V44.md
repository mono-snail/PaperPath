# PaperPath V44：版本校样、原子页面生产与审计账本

## 本轮目标

V43 已把 PaperPath 建成持续分栏工作台，但专业生产链仍有四个断点：PDF 对比停留在临时弹窗，页面台不能原子替换或规则重排，Inspector 动作固定，隐私与存储状态仍分散在多个旧式章节。V44 将这些底层能力串成同一套本地 PDF Studio 工作流：

- iPad 同一窗口持续并排校样两份 PDF。
- 页面替换、选择和重排保持确定性、可预览、可恢复。
- Inspector 成为可排序的个人工作位，而不是固定入口列表。
- 隐私、容量和废纸篓统一为高密度审计账本。
- 对比和页面几何分析按内容修订缓存，降低大文档重复成本。

产品定位继续收紧为：**在本机校样、修订并验证重要 PDF，保护导入原件，让每次结构变更均可追溯和恢复。**

## TOP3 竞品证据

检索日期：2026-08-18。

- Adobe Acrobat Pro 的 Compare Files 会分析两份 PDF、生成差异报告，并提供旧版/新版并排视图、变化跳转和类型筛选。PaperPath 对标并排与变化导航，但把结果留在 iPad 持续工作区，并坚持本机确定性比较。
  - https://helpx.adobe.com/acrobat/using/compare-documents.html
- PDF Expert iPad 支持并排查看两份 PDF，也允许显示、隐藏和移动工具组。PaperPath 对标其多文档工作效率，并把比较对象、同步页码和 Inspector 工作位一起跨会话保存。
  - https://support.readdle.com/pdfexpert/en_US/reading-pdfs/view-two-pdfs-side-by-side-on-ipad
  - https://support.readdle.com/pdfexpert/en_US/tips-and-tricks/work-with-pdf-tools-and-customize-the-toolbar
- UPDF 的页面整理覆盖替换、插入、提取、拆分、旋转、删除，以及奇数、偶数、横向、纵向页面选择。PaperPath 补齐同类刚需，并增加纸张规格组合规则、完整排列校验和操作前恢复快照。
  - https://updf.com/updf-windows-user-guide/organize-pages/
  - https://updf.com/updf-ios-user-guide/organize-pages-ios/

## 本轮全部优化

- iPad 持续双 PDF 对照校样台。
- BASE/REVISED 身份、交换、关闭与同步/独立翻页。
- 可见、文本层、页面几何差异计数。
- 上一处/下一处变化直接导航。
- 对照对象、页位与同步设置跨会话恢复。
- 原子页面替换，保持页数和目标索引。
- 来源 PDF 与来源页缩略图选择。
- 页码、方向、纸张规格组合选择。
- 全量反向、奇偶分组、偶奇分组、双半区交错。
- 完整排列校验、书签重映射和一步撤销。
- Inspector 最多五个可排序工作位。
- Inspector 默认复用工具收藏，支持增删、移动和恢复推荐。
- 隐私处理账本：对象、位置、生命周期、边界。
- 存储容量账本：类别、大小、占比、保留策略。
- 废纸篓保留账本：容量、到期风险、移除时间与恢复动作。
- 修订感知的 PDF 对比缓存和页面几何缓存。
- V44 可见流程简体中文覆盖。

## 相比竞品的新增优势

- 相比 Acrobat 生成独立比较报告，PaperPath 把确定性结果直接接入 iPad 持续工作区，资料库和 Inspector 不消失。
- 相比 PDF Expert 的通用双窗口，PaperPath 额外提供内容修订感知缓存、同步页码、变化页导航和跨会话校样恢复。
- 相比 UPDF 的页面替换和规则选择，PaperPath 每次结构写盘前创建本地保护快照，并验证规则包含全部页面且不重复。
- 三款竞品强调功能工具；PaperPath 将校样、页面生产、隐私边界、存储保留与恢复契约连成一条本地审计链。

## 当前剩余短板

- 双 PDF 校样目前按同页索引同步，尚未提供跨页重排后的相似页自动配对。
- 差异导航展示页级证据，尚未在 PDF 页面内叠加像素差异热区。
- 页面替换目前从资料库内另一份 PDF 选择，不直接从 Files 临时选取单页。
- Inspector 配置按设备保存，尚未纳入可选 iCloud 元数据同步。
- 账本已完成代码层重构，但本轮按要求未进行截图回归和实机视觉验收。
- 本轮未执行单元测试、UI 测试或发布门禁。

## 下一轮精准方向

1. 增加页面相似度配对，处理插页或删页后的跨索引校样。
2. 生成可开关的页面差异热区，并保持 PDFKit 选择和缩放手势。
3. 页面替换支持临时 Files 来源和替换前后几何预警。
4. 审计账本增加按风险、容量和到期时间排序。
5. 单独执行 iPad 分屏、辅助字号、VoiceOver、低内存和长文档视觉验收。

xcodebuild -project PaperPath.xcodeproj -scheme PaperPath -configuration Debug -destination 'generic/platform=iOS Simulator' build CODE_SIGNING_ALLOWED=NO
