# PaperPath V45：本机修订控制台、跨页校样与外部页面生产

## 本轮目标

V44 已建立双 PDF 校样、页面规则台和三类审计账本，但专业修订链仍有四个结构性断点：

- 对比按相同页码进行，一次插页会让后续页面全部错位。
- 差异只有页级计数，没有严重度、插入/移除类型和位置证据。
- 版本历史能恢复，却不能在恢复前与当前副本比较。
- 页面替换必须先将来源 PDF 导入资料库，临时修订页路径过长。

V45 将 PaperPath 从“PDF 工具集合”继续收紧为：**保护原件的本机 PDF 修订控制台，在同一条工作流内完成历史版本校样、结构差异复核、外部修订页替换、恢复与交付审计。**

## 本轮全部优化

- 文本/视觉唯一指纹锚点和最长递增页面配对。
- 修改、插入、移除、未变化四类页面结构。
- Critical、Major、Minor 三档变化严重度。
- 6×6 差异位置网格与最多 12 个热区证据。
- iPad 校样变化轨及全部/关键/结构过滤。
- 来源页与修订页独立页码映射。
- 配对感知的同步翻页和变化跳转。
- 旧交付凭证 Codable 向后兼容。
- 历史版本完整性校验后的受控预览。
- 恢复前“已保存版本 vs 当前副本”修订台。
- Inspector 当前版本与最近三份保护版本时间线。
- Inspector 可配置 Version History 工作位。
- Files 外部 PDF 临时页面替换。
- 安全作用域读取、完整文件保护和退出清理。
- 目标页与来源页尺寸、方向、纸张规格预警。
- 隐私账本边界聚焦。
- 存储账本大小/类别排序。
- 废纸篓到期/移除/容量排序。
- 超长文档分层渲染预算与配对复杂度上限。
- 历史版本比较有界缓存和内存警告释放。

## 相比竞品的新增优势

- 相比 Acrobat 独立生成比较报告，PaperPath 的页面配对、变化轨和两个 `PDFView` 共存于持续 iPad 工作区，资料库与证据 Inspector 不消失。
- 相比 PDF Expert 的通用文件和大文档工作流，PaperPath 把本地保护版本变成可预览、可比较、再恢复的修订控制台。
- 相比 UPDF 的页面替换，PaperPath 的 Files 来源不必先进入资料库，临时副本受完整文件保护，并在替换完成或取消后删除。
- 全部结构写盘仍先创建本地恢复快照；导入原件、历史修订、当前工作副本和外发交付之间的边界保持明确。
- 页面对齐与热区完全确定性、本机运行，不把合同、证据或图纸发送至 AI 服务。

## 当前剩余短板

- 热区目前显示在变化轨缩略图中，尚未作为与缩放同步的 PDF 页面覆盖层。
- 页面配对能识别唯一稳定页和局部重排，但大量重复模板页仍可能退化为顺序配对。
- 版本修订台显示前四项变化，尚未直接进入全屏历史版本双 PDF 工作区。
- Files 外部替换仅接受 PDF，尚未在同一入口接入扫描和照片转页。
- Inspector 时间线显示最近三份版本，尚未支持固定某个里程碑版本。
- 本轮按要求未执行单元测试、UI 测试、截图回归和发布门禁。

## 下一轮精准方向

1. 将归一化差异区域转换为 PDFView 坐标覆盖层，并随缩放、旋转和裁切同步。
2. 增加重复模板页的邻域指纹和章节文本上下文，提升大批相似页面配对质量。
3. 支持从版本修订台直接进入历史版本双 PDF 校样，并保留当前变化索引。
4. 为保护版本增加里程碑名称、固定保留和交付凭证关联。
5. 单独执行 iPad 分屏、辅助字号、VoiceOver、低内存和 500 页以上 PDF 的视觉与性能验收。
