# 恢复工作流与批量效率迭代

日期：2026-09-13。状态：R1-R7 已完成。接续同日竞品导向迭代，保留原有工作区更改。

本轮目标：让中断恢复、修正后复核和多文件选择成为可发现、可确认、可追溯的完整路径。
竞品依据沿用 [同日官方资料复核](PRODUCT_ITERATION_2026_09_13_ZH.md)，
接续 [上一轮执行记录](COMPETITIVE_EXECUTION_2026_09_13_ZH.md)，未重新安装并计时全部竞品。
截图、诊断与构建日志见 [验收证据索引](../design/recovery-workflow-2026-09-13/README.md)。

## 当前缺口

1. OCR 配置入口只查询与当前参数匹配的进度，重新打开后不易找回之前选择的语言、词表。
2. 查询保存页数会把全部已识别文字留在内存；设置页只需要摘要，不需要完整文字对象。
3. 更改识别设置并开始会替换旧检查点，缺少明确的进度替换确认。
4. 批量源文件修正后因修订不匹配被过滤，原批次不再能继续复核该文件。
5. 批量选择缺少搜索，全选会替换选择，用户不易核对过滤范围外的文件。

## 约束

不新增服务或账户依赖，不修改收费策略，不修改 PDF 引擎。源文件修订继续强绑定；
批量重新检查不得绕过任意 review/blocked 项。保留正式 OCR 结果与已提交 PDF。
不运行真实购买、不开外部分享，不清除原资料库。验证用隔离合成样本。

## 验收记录

### R1：恢复摘要

`OCRRecoverySummary` 只返回身份、完成页码和损坏页数。
`DocumentStore.scanOCRCheckpoint` 同时服务实际恢复和摘要查询，沿用受保护普通文件、
修订/页数/引擎/系统版本检查以及编码大小、文字和文本块预算。
摘要逐页读取和校验后释放文字，不把全文数组交给设置页；坏页不计为完成页。
摘要查询不写入或替换检查点。

两台诊断验证：有效页集合一致，损坏第二页时仅剩 `[0, 2]` 可复用；
损坏计数为 1，实际恢复只重算该页。没有测量峰值内存、耗时提升或大库 I/O。

### R2：恢复原识别设置

入口主动查找当前修订的保存配置，不要求用户记住上次参数。
显示保存页数、语言、词条数量和需重算页数；“恢复原识别设置”恢复语言与词表，
只有配置一致才显示“继续识别”。查询失败有持久提示及重试，期间不允许启动。
查询按请求身份、文档修订和前台状态收敛，不因每次输入词条重复扫描磁盘。

iPhone 实操从保存一页恢复 `en-US`、`PaperPath`、`Invoice`，继续后正式结果三页，
原配置完整保存，`.resume` 目录清理；正式存储核对已归档。

### R3：替换确认和后台状态

使用不同参数且存在已完成页时，启动前要求明确确认替换保存进度；
现有 PDF 和正式文字结果不因取消被删除。iPhone 点击外部取消确认弹层后，
`identity.json` 与 `page-0.json` 的 SHA-256 都不变。

后台、受保护数据不可用时清摘要、待确认参数与词表，并关闭配置页。
iPad 实操恢复词表后按 Home，返回前台不再显示配置页；检查点两份文件指纹不变。
重新打开可再次发现一页保存进度，当前词条输入已清空，仍可恢复原设置。
这是模拟器后台行为验证，不等同真机锁屏、进程内存擦除或系统快照隐私审计。

### R4：修订变化的批量复核

原批次不再过滤仍存在、可处理但修订已变化的源文件。变化项统一为待复核 `S-002`，
清除旧输出引用及问题页导航；既有输出文件仍保留在成果中。
确认重查时快照当前修订，执行时再次验证 `expectedRevisionIDs`，避免确认后换版。
收尾检查统一了 UI 中“确认后再次变化”的状态，不再落入通用失败项。

生产模型诊断覆盖三项批次保存/重启、旧修订请求拦截、确认当前修订后新增一份输出，
另一份既有成功输出仍保留。iPad 实操看到变化项和重查确认；
确认后正常进入现有购买授权页，未购买、未绕过收费。成功重查由隔离模型诊断验证，
不宣称完成真实购买后的 UI 全链路。

### R5：搜索与选择

文件名和标签可搜索；结果阶段额外匹配状态和说明。输入限 256 字符，支持清除和
Command-F。增加/取消匹配项只影响匹配集合，显示搜索范围外已选数量，
空结果不改变选择且禁用增加按钮，批次上限仍为 64。

iPad 输入 `form`：列表一项、总计四项、范围外三项；取消匹配后总计三项，
重新选择回到四项。无匹配查询保留四项，后台返回清查询但保留四项。
iPhone 常规字号同样显示隐藏选择；最终构建最大辅助字号实际取消后保留外部三项。
生产 `PDFBatchSelection` 的 10 个容量、去重、空集合、非正上限断言通过。

### R6：布局和运行回归

保持原生列表、实际 PDF 缩略图、语义状态色和现有选择动效。
最大辅助字号截图发现批量标题、底部操作占高过大，搜索图标被一同放大。
最终仅对紧凑标题和主要底部命令采用项目已有的 `accessibility1` 字号上限，
图标固定 20pt、44pt 命中区；文件、选择计数和搜索文字继续支持最大字号。
修正后标题、主操作和匹配选择互不覆盖，文件列表可滚动；未声称完整 VoiceOver 验收。
