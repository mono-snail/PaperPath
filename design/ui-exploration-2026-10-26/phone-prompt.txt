Use case: ui-mockup. Create a high-fidelity product UI design exploration for PaperPath, a REAL existing iOS 17+ native offline PDF utility for iPhone and iPad. This is a visual concept, not a marketing landing page. Output a clean design review board showing THREE complete portrait iPhone screens side by side at equally readable scale, no hardware device bezels, on a neutral surrounding canvas: Documents home, Merge PDFs with selected sources, Compress PDF. Small board labels outside screens only.

PRODUCT BACKGROUND: busy people handling invoices, contracts and scanned documents need to finish a small PDF task confidently, on their device, while preserving the original. Existing features: import from Files, camera scan, merge, split/extract and organize pages, three compression qualities with sampled size estimates, Apple Vision local OCR and searchable copies, reading/annotation, form filling and signatures, privacy scan/redaction, password protection, conversion, verified output receipts. One-time optional unlock for verified output, no subscription. Do not add new features, AI chat, collaboration, cloud storage, dashboards, invented usage statistics or pricing.

REFERENCE ROLES: image 1 is the current real iPhone home, source of exact actions/navigation and existing visual identity; image 2 is real merge screen, source of actual selection, names, controls and safety; image 3 is a real iPad reader, evidence of document-first native product scope, not a phone layout to copy. References are functional evidence; redesign layout and hierarchy deliberately rather than tracing them.

CURRENT WEAKNESSES TO SOLVE: duplicated app/page titles and large empty vertical spaces push document content down; 2x2 quick actions occupy too much height with long horizontal dividers; merge exposes repeated uppercase section labels and scatters order, available sources and naming across a long scroll. Many tint circles and explanatory labels create visual noise. Main task controls need one clear hierarchy.

ART DIRECTION: a quiet precise document workbench, made of typography, paper thumbnails, spatial rhythm and native controls. Light warm neutral canvas, near-white surfaces, ink-charcoal text, one restrained deep blue action accent; small green only for actual success and amber for warnings. No decorative gradients, illustrations, 3D, texture backgrounds, large ornamental shield badges, glassy floating pills, shadows around everything, or generic repeated equal-weight cards. Native SF-style sans text and crisp SF-style icons; retain subtle serif only if it helps one page title. One page title per screen, compact navigation, 44pt targets, readable secondary text, 16–20pt margins, adaptive layouts possible at large text sizes.
