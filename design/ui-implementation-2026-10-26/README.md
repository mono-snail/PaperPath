# 第二轮 UI 方案实装 · 2026-10-26

本目录保存实际 iOS Simulator 截图与验收记录。视觉来源是 `design/ui-exploration-2026-10-26/phone-v2.png` 和 `ipad-workbench.png`；完整 Image Tool 提示词留在原目录。本轮未将生成的 UI 图片贴进 App，全部使用原生 SwiftUI 控件。

## 已实现

- 首页保留 Import、Scan、创建入口，手机移除重复的大标题，四个常用操作改为紧凑图标工具区。文档列表获得更多首屏空间。
- 合并页用文件数、页数与大小代替大幅重复页头。已选顺序优先；手机选到两份后自动收起文件库，可再次展开或搜索。缩短排序行，保留拖动、移除、排序菜单及无障碍移动操作。
- 压缩的单份与批量入口收紧页头。保留原生三档选择、源文档身份、真实大小预估、估算中/失败/重试、图像化损失说明与原件保护。
- iPad 工作区收紧文档侧栏；Tools 按需打开右侧检查器，先显示真实可用的表单、签名、整理页面、压缩、OCR、可信输出入口。证据、版本记录和原有自定义操作保留在文档详情内。打开处理任务后收起检查器，恢复阅读布局。
- 继续使用既有深浅色语义色、文件兼容性和任务生命周期；新增缩略图遵守隐藏预览偏好。

按用户要求，本轮不做大字号专项调优与测试；没有移除既有自适应分支。

## 验收范围

手机：首页四入口打开与取消、合并真实拖动与输出、单份与批量压缩的原件保护。

iPad：检查器展开、工具可用性、打开压缩、关闭任务后恢复阅读布局。

原有两个模拟器被其他测试任务占用，本轮使用独立的 PaperPath UI Design iPhone/iPad 模拟器，避免相互安装或终止应用。并行发生的 OCR、商务测试与发布审计修改不属于本轮 UI 改动，予以保留。

静态截图验证布局，XCTest 验证行为。本轮不宣称通过真机发布认证或完整全套回归。

## 验收结果

编译通过，5 条关键界面流程通过；最后的 iPad 标题和 Tools 标签精修后，再次验证检查器与压缩流程通过。自动化覆盖契约、字符串资源验证和 diff 格式检查通过。详见 `validation.txt`。
